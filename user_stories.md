
# User Stories – Doctor Patient Management System

## 1. Doctor User Stories

- As a Doctor, I want to log in securely so that I can access my account.
- As a Doctor, I want to view my appointments so that I can manage my schedule.
- As a Doctor, I want to view patient medical records so that I can provide appropriate treatment.
- As a Doctor, I want to update patient diagnoses and prescriptions so that medical information stays up to date.
- As a Doctor, I want to manage my availability so that patients can book appointments.

## 2. Patient User Stories

- As a Patient, I want to register an account so that I can use the system.
- As a Patient, I want to log in securely so that my personal information is protected.
- As a Patient, I want to search for doctors so that I can find the right specialist.
- As a Patient, I want to book appointments so that I can consult a doctor.
- As a Patient, I want to view and cancel my appointments so that I can manage my schedule.
- As a Patient, I want to view my medical history and prescriptions so that I can track my health.

## 3. Admin User Stories

- As an Admin, I want to log in securely so that I can manage the system.
- As an Admin, I want to manage doctor accounts so that doctor information stays updated.
- As an Admin, I want to manage patient accounts so that user information is organized.
- As an Admin, I want to view and manage all appointments so that the system operates smoothly.
- As an Admin, I want to add, update, and delete user accounts so that I can control system access.
- As an Admin, I want to generate reports so that I can monitor system activity.
